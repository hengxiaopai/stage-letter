# 小程序 UI 实施基线

更新：2026-08-22

## MVP 首页

- 视觉以用户提供的 `09空状态示例.png` 与 `01首页-我的订阅.png` 为基准：浅蓝背景、白色圆角信笺卡片、品牌蓝 CTA、红色仅用于直播状态。
- 首页先回答两个问题：谁正在直播；我订阅了谁。空状态必须提供进入发现页的明确下一步。
- `0` 个订阅：同时显示“暂无主播在直播”和“暂无订阅的主播”两张卡片。
- 有订阅但 `0` 个直播：保留“暂无主播在直播”卡片，并继续展示全部订阅，不能让离线主播消失。
- 已开播主播优先展示在横向“正在直播”区；订阅清单保持状态排序：直播中、确认中、未知、未开播。

## 公共品牌头与公告条（冻结规范）

所有首页状态稿、发现页、消息页和我的页面复用同一套公共组件；页面原型不得自行重绘或变更它们。

### 品牌头

- **唯一图标资产**：`miniapp/assets/brand/stage-letter-mark.png`。不得以 AI 生成的线框信封、无爱心信封或其他信封代替。
- **位置**：内容区左对齐，位于小程序胶囊下方；图标、`开场信` 和 `StageLetter` 组成一个固定品牌组。
- **文字**：`开场信` 使用品牌蓝、加粗；`StageLetter` 位于其下，较小、同色或浅一阶蓝色。不得改成深黑标题或单独只显示图标。
- **尺寸**：图标 `66rpx × 66rpx`，文字组左间距 `14rpx`；外部上下间距由 `home-brand-header` 统一控制。

### 公告滚动条

- **位置**：品牌头/搜索框之后，首页主要内容之前；左右边距与搜索框一致。
- **结构固定**：蓝色喇叭图标 → `公告` 标签 → 单条循环滚动文案 → 右侧细箭头。不能删除标签、换成静态长文本，或在不同状态稿中使用不同图标。
- **样式**：高度 `70rpx`、圆角 `14rpx`、浅蓝底 `#EDF4FF`、品牌蓝文字；文本区域裁切，循环动画只滚动正文，不滚动图标与“公告”。
- **行为**：点击整条可进入公告/活动说明（未接入前展示“暂未开放”反馈）；动画暂停或弱动效设置下保留可读静态文本。

### 原型使用规则

用户提供的 `01首页-我的订阅.png` 与 `09空状态示例.png` 是上述公共组件的视觉源头。AI 生成图仅用于验证不同数据状态下的布局，若与公共组件不一致，必须以本规范和正式资产为准，随后重生成或在实现图中修正。

## 资产

- `miniapp/assets/brand/stage-letter-mark.png`：首页品牌信封图标。
- `miniapp/assets/empty/no-live-letter.png`：无主播直播空态插画。
- `miniapp/assets/empty/no-subscriptions-parcel.png`：无订阅空态插画。

后续页面继续采用此基线，但不要把主播专属的活动、积分、商城等内容放到全局首页。
