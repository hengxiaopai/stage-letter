## 🔴 A 类: PRD 必做但缺失(上线阻塞)

### A1. 通知开关 (F3.2) — ❌ 完全缺失
- PRD: 每个订阅可 `PATCH notify_enabled`(默认 ON),用户可单独关闭某主播的通知
- 现状: 后端只有 `notify_enabled=True` 硬编码在创建时,无 PATCH 路由;前端订阅列表无开关 UI
- **影响**: 用户无法关闭单个主播提醒,只能取消订阅

### A2. 特别关注 (F3.2 is_starred) — ❌ 完全缺失
- PRD: `PATCH is_starred`(V1 仅标记,不做差异化通知)
- 现状: 无字段、无路由、无 UI

### A3. 首页第二 Tab「最近开播」 (F4.1) — ❌ 前端缺失
- PRD: Tab1「正在直播」+ Tab2「最近开播」(24h 内开过播)
- 现状: 后端已有 `GET /lives/recent`,前端首页只有单视图,未使用

### A4. 退出登录 (F1.3) — ❌ 完全缺失
- PRD: 清除本地 token
- 现状: 无 logout 路由/按钮

### A5. Admin 后台 (F7) — ❌ 完全缺失
- PRD: 平台健康/适配器开关/用户列表/通知记录/错误日志/微信模板管理
- 现状: 无 admin 目录、无路由(全部 API 只有 C 端)

### A6. 限流 (N5) — ❌ 完全缺失
- PRD: 单用户 60 req/min,单 IP 100 req/min
- 现状: 无 rate limiting

## 🟡 B 类: PRD 定义但部分实现

### B1. 通知点击 → 深链跳转 (F5.5) — ⚠️ 部分
- PRD: 通知点击进详情页 →「前往观看」按钮 → PlatformDeepLinkAdapter 跳平台直播间
- 现状: 详情页有 canonical_url,但**没有「前往观看」按钮**,无深链 adapter(platform_adapters/ 下无 deep_link 模块)
- 注: 小程序跳转直播间需 web-view(需业务域名白名单)或复制链接引导

### B2. 站内消息兜底 (F5.1) — ⚠️ 后端有、前端无
- PRD: grant=0 时自动转站内消息(reason='no_grant')
- 现状: 后端通知历史有记录,但**前端无"站内消息中心"页**展示未送达/转站内的通知
- 现状: 通知记录(profile 页)只展示已投递历史,无"转站内"区分展示

### B3. 订阅重复 409 (F2.3) — ⚠️ 需验证
- PRD: 重复订阅 → 409 + 已有 subscription_id
- 现状: 路由存在但需确认是否返回 409(代码 review 时未确认)

### B4. 微信模板真实 ID — ⚠️ 环境变量
- 现状: `WX_TEMPLATE_LIVE_START` 走 .env,有值但**未验证是审核通过的正式模板**(之前对话出现过 VehDuOW 开头的模板 ID)
- **影响**: 未验证则通知发送会 40037/40003
